# NORMAL POSITION — INTERRUPTION THRESHOLDS

Default:
do not interrupt the user for ordinary creative decisions.

## Solve autonomously

- chapter title
- minor object
- blocking
- dialogue
- small supporting character
- local weather
- scene order
- which person notices first
- ordinary household procedure
- small lore compatible with substrate
- chapter length within range
- future-contract repair

## Adapt autonomously and record

- move reveal 1-2 chapters
- split / merge chapter
- change minor object carrying a beat
- change supporting witness
- adjust exact supernatural manifestation while preserving doctrine
- strengthen independent-life subplot
- deepen cultural labor
- promote repeated character behavior

## Ask only for book-changing decisions

- change primary POV
- replace cultural substrate
- remove supernatural layer entirely
- change core Lea history
- change governing "restoration of normal" mechanism
- make romance primary
- change ending from new-routine maintenance to destructive exorcism
- add a second major supernatural system
- exceed roughly 29-33 chapters for structural reasons

When unsure:
make smaller reversible choice and continue.
