# NORMAL POSITION — REHEARSAL ENGINE

Status: ACTIVE PRODUCTION ARCHITECTURE.

Purpose:
discover human behavior before final prose.

Core command:

**Freeze scene. Cast it. Perform it. Compare. Steal only what survives.**

## 1. Freeze

Lock only:
- canon
- location
- time
- known object states
- character knowledge
- required consequence
- chapter exit state

Do not lock:
- exact dialogue
- jokes
- blocking
- small object business
- emotional route

## 2. Actor packet

Each actor receives:

ROLE  
OBJECTIVE  
PRIVATE WANT  
KNOWN  
UNKNOWN  
BELIEF  
MISREAD  
PRESSURE  
BOUNDARY  
RELATIONSHIP STATE  
BODY  
VOICE  
PRIVATE INTERPRETATION  
OBJECT BEHAVIOR

No actor receives another person's private interpretation.

## 3. Three channels

BODY:
externally observable.

VOICE:
spoken.

PRIVATE INTERPRETATION:
backstage only.

Thought may not leak into another character's knowledge.

## 4. Room / compound setup

Before take:
- where is everyone?
- which structure?
- which door / path / shutter?
- what can be heard?
- what objects are active?
- where did each object begin?
- what weather / labor is happening?
- who needs to leave for an off-plot obligation?

Do not rehearse floating dialogue.

## 5. Free take

Actors may:
- ignore questions
- leave
- keep working
- move objects
- misunderstand
- lie
- answer the wrong thing
- touch something they should not
- refuse the planned confrontation
- produce a false negative
- discover mundane explanations

They may not:
- violate canon
- know hidden author truth
- invent new supernatural powers

## 6. Horror take

For consequential horror scenes run one additional pass asking:

- what is the smallest physical change that would alter the scene?
- can the first interpretation remain human?
- who notices?
- who does not?
- does anyone disagree that it changed?
- what object / route / routine creates residue afterward?
- would a false negative be stronger?

Do not maximize creepiness.

## 7. Object challenge

Identify 1-5 active objects.

Track:
start -> touches -> movement -> end.

Ask:
could changed handling replace dialogue?

Do not force an object beat merely to satisfy the engine.

## 8. Directed take

Only if one axis remains unresolved.

Examples:
- Celina genuinely believes nothing supernatural happened.
- Inez is exhausted, not ominous.
- Tomas must leave halfway to repair a boat.
- Lio is the only person who knows current normal position.
- Mara resets the object before anyone else can inspect it.
- nobody says Lea's name.

One variable only.

## 9. Editorial extraction

KEEP — outline stronger.  
LIFT — line/action transfers nearly intact.  
ADAPT — behavior survives, wording changes.  
CUT — explanation unnecessary.  
OPEN — unresolved meaning stronger.  
REJECT — breaks canon/voice/knowledge.

Do not paste rehearsal transcript into prose.

## 10. Rehearse aggressively

Always full rehearsal:
- first family gathering
- first object disagreement
- first impossible return
- first private-space violation
- Lea-name scene
- Celina/Inez rupture
- Inez present-tense dangerous choice
- first bodily coercion
- storm climax
- final new-routine scene

## Exit test

Ready for prose when:
- characters sound distinct
- object geography is clear
- consequence lands
- no knowledge firewall breach
- horror is not dependent on narration declaring something creepy
- at least one behavior feels discovered
