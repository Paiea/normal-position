# NORMAL POSITION — OBJECT ENGINE

Status: ACTIVE PRODUCTION AUTHORITY.

The rule is not:
**make objects creepy.**

The rule is:
**make objects familiar enough that wrongness becomes legible.**

## Core

Objects exist before horror needs them.

Recurring objects may have:
- owner
- keeper
- normal location
- normal orientation
- normal user
- touch permission
- cleaning / maintenance routine
- relational history
- last confirmed location
- current location
- current condition

Do not inventory the whole house.

Track objects whose normal state matters to life.

## Familiarity before contamination

A useful object arc may be:

NORMAL
-> SLIGHTLY WRONG
-> PLAUSIBLE
-> NORMAL AGAIN
-> SECOND DEVIATION
-> DISAGREEMENT
-> PERSONAL CONSEQUENCE
-> IMPOSSIBLE OR INTOLERABLE STATE

Do not mechanically advance.

## Normal position

Before displacement matters:
establish normal position without spotlighting it.

The first key-on-hook beat should feel like life, not foreshadowing.

## Objects prove unseen action

High-value residue:
- warm cup
- wet basin
- wrong fold
- changed knot
- missing food
- closed drawer
- moved chair
- returned key
- tool cleaned differently
- shutters latched in another order

The question:
**who touched this?**

Later:
**how did they know how it normally belongs?**

## Impossible normality

Sometimes the frightening object is exactly where it belongs when that should be impossible.

Use sparingly.

Example:
Mara watches an object leave the compound.
Later it is back in its ordinary place.

The fear comes from correct placement.

## Touch rules

Track the difference between:
- can touch
- normally touches
- is allowed to touch
- morally should touch

Changed touch rules can move relationships without dialogue.

## Culture

Object meaning must come from actual life:
food storage, storm preparation, tools, sleeping, hospitality, mourning, work.

Do not fill the house with generic creepy antiques.

## Object rehearsal

For consequential scenes choose 1-5 active objects.

Know:
- start location
- touches
- movement
- visibility
- end location
- whether movement is ordinary
- who cares

Allow actor improvisation to discover object behavior.

## Audit

Ask:
- was normal established?
- did it move plausibly?
- who could notice?
- did narration make it suspicious before characters had reason?
- could human action explain it?
- did the object replace explanation?
- are too many objects weird?
- are ordinary objects still ordinary?
- is another person's mundane expertise relevant?
- did we explain the beat after it landed?
