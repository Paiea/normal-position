# NORMAL POSITION — CROSS-PROJECT ALIGNMENT

Status: ACTIVE.

Parallel project:
**Nothing False on the Stage** / repository no-props.

## Shared Generation-2 chassis

Both projects inherit:
- culture before prose
- objects as practical life
- independent characters
- frame-breakers
- strengths become expensive
- possibility != canon
- rehearsal before consequential prose
- nonverbal behavior
- audio clarity
- explanation audit
- future contracts mutate
- climax uses established mechanics

## Canon firewall

Nothing from NO PROPS is canon here.

Nothing from NORMAL POSITION is canon there.

Cross-project ideas may be copied only at the level of:
- process
- audit question
- rehearsal method
- craft lesson

Do not transfer:
- plot
- culprit
- character
- cultural detail
- scene
- motif merely because it worked elsewhere

## Object divergence

NO PROPS:
objects are forensic grammar.
Question:
**where was it, who touched it, what does that prove?**

NORMAL POSITION:
objects are domestic memory and contamination.
Question:
**what does this ordinary thing reveal about access, routine, family, and whose normal is being enforced?**

## Knowledge divergence

NO PROPS should become more knowable with expertise.

NORMAL POSITION may become less emotionally safe as behavior becomes more knowable.

Do not turn this book into a fair-play supernatural mystery where every uncertainty receives a clean solution.

## Sync rule

If either project discovers a reusable craft improvement:
1. abstract it
2. test whether it serves the other genre
3. adapt rather than copy
4. preserve tonal difference
